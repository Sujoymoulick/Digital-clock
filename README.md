# 🕒 3D Interactive Digital Clock

A modern, fully **responsive digital clock** featuring a captivating **interactive 3D background**.  
Built to blend functionality with aesthetics — this web app displays real-time time & date while showcasing a mesmerizing **Three.js Dodecahedron** that subtly rotates and reacts to your cursor ✨.

## ✨ Key Features

- 🕰 **Real-Time Clock Display** — Shows current time in `HH:MM:SS` format with AM/PM.  
- 📅 **Dynamic Date Display** — Auto-updates daily.  
- 📱 **Fully Responsive Layout** — Built with **Tailwind CSS**, ensuring a seamless experience on all devices.  
- 🌐 **Interactive 3D Background** — A **Three.js Dodecahedron** rotates smoothly and follows cursor movement for a futuristic vibe.  
- 🚀 **Quick Navigation Buttons** — Includes GitHub link & a handy browser “Back” button for smooth navigation.  
- ✨ **Animated Logo** — A stylish, animated project logo adds a lively touch to the UI.

---

## 🛠 Technologies Used

- 🧱 **HTML5** – Structure of the web app  
- 🎨 **Tailwind CSS** – Responsive, utility-first styling  
- ⚡ **Vanilla JavaScript** – Real-time clock logic & interactivity  
- 🌐 **Three.js** – For rendering and animating the 3D Dodecahedron
